# نظام إدارة المشاريع البرمجية

نظام مبسط لإدارة المشاريع والمهام باستخدام ASP.NET Core.

---

## جزء التقارير

تم تطوير صفحة تقرير لعرض حالة المشروع بشكل مبسط واحترافي.

### الإحصائيات المعروضة

- إجمالي عدد المهام.
- عدد المهام المنجزة.
- نسبة الإنجاز الكلية للمشروع.
- عدد المهام المتبقية.

### حساب نسبة الإنجاز

يتم حساب نسبة الإنجاز باستخدام المعادلة التالية:

Completed Tasks / Total Tasks × 100

مثال:

إجمالي المهام: 5  
المهام المنجزة: 3  
نسبة الإنجاز: 60%

## قاعدة البيانات

تم استخدام Entity Framework Core لإنشاء وربط قاعدة البيانات.

الجداول المرتبطة بهذه الجزئية:

### Users

- Id
- Name
- Email

### Tasks

يتم استخدام بيانات المهام لحساب إحصائيات التقرير.

---

## صفحة التقرير

تعرض صفحة التقرير:

- إجمالي المهام.
- المهام المنجزة.
- المهام المتبقية.
- نسبة الإنجاز.
- شريط تقدم بصري.
- حالة تقدم المشروع.

المسار:

/Report

---

## تشغيل المشروع

1. فتح المشروع باستخدام Visual Studio.
2. التأكد من إعداد اتصال قاعدة البيانات.
3. تنفيذ:

Update-Database

4. تشغيل المشروع.
5. فتح صفحة التقرير من:

/Report

## Git Workflow

مثال:
